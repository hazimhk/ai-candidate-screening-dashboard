# AI Candidate Screening Dashboard

A full-stack AI-first application that helps recruiters manage candidates, summarize resumes, and generate interview questions using AI.

## Why I Built This

I built this project to strengthen my full-stack skills and practice AI-assisted engineering. My strongest background is frontend, so this project helped me work across frontend, backend, database, authentication, and AI integration.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- PostgreSQL
- Prisma
- OpenAI API
- Vercel

## Features

- Candidate management
- Resume text input
- AI-generated candidate summary
- AI-generated interview questions
- Candidate scoring
- Search and filter
- Authentication

## What I Practiced

- API design
- Database schema design
- Authentication
- AI prompt design
- Error handling
- Full-stack deployment
